# POO_1
Proyecto Final: Administrador de Tintorerías

Este repositorio es una recopilación de todos los ejercicios realizados durante la materia de Programación Orientada a Objetos, así como el proyecto final de la materia. Desde los conceptos básicos hasta la implementación de un sistema completo, este repositorio refleja el aprendizaje progresivo, paso a paso.

El proyecto final es una aplicación diseñada para administrar tintorerías, con funcionalidades clave como:

Alta de clientes: Registro y almacenamiento de información de clientes en una base de datos SQL.

Creación de órdenes: Generación y gestión de pedidos relacionados con los clientes.

Agregado de prendas a las órdenes: Detalle de las prendas dentro de cada orden, incluyendo atributos como tipo, precio y descripción.

Todo está organizado para facilitar su comprensión y reflejar cómo se aplicaron los conceptos teóricos a un sistema funcional. A continuación, se explican los elementos incluidos en este repositorio:

1. Creación de Clases

a) Trabajo en Clase Uno: Encapsulamiento, Herencia, Clases y Polimorfismo

Este ejercicio introduce los conceptos fundamentales de la Programación Orientada a Objetos (POO):

Encapsulamiento: Protección de datos dentro de una clase, ocultando su implementación interna y exponiendo sólo los métodos necesarios.

Herencia: Creación de nuevas clases basadas en clases existentes, fomentando la reutilización del código.

Clases: Definición de la estructura y el comportamiento de los objetos.

Polimorfismo: Flexibilidad al permitir que métodos compartan una misma interfaz pero tengan implementaciones diferentes.

b) Trabajo en Clase Dos: Clases y DataFrames

Este ejercicio aborda el uso combinado de clases y DataFrames para manejar datos estructurados. Aplicamos los principios de la POO al procesamiento de datos, encapsulando lógica y métodos relacionados con el análisis y manipulación de datos. Esto mejora la organización y reusabilidad del código.

2. Proyecto Final: Administrador de Tintorerías

El proyecto final consiste en una aplicación con interfaz gráfica de usuario (GUI), diseñada para la administración de tintorerías. Este sistema integra funcionalidades completas para gestionar clientes y órdenes, con datos relacionados a una base de datos SQL.

Principales Características

Alta de clientes: Permite registrar clientes en el sistema, guardando su información en una base de datos SQL.

Creación de órdenes: Gestiona pedidos asociados a los clientes.

Agregado de prendas: Integra un sistema para especificar y detallar prendas dentro de cada orden.

Base de datos SQL: Los datos se almacenan y consultan mediante una base SQL, asegurando integridad y escalabilidad.

3. Lectura de Datos (Consultas) con Pandas

El manejo de datos y consultas se abordó utilizando la biblioteca Pandas de Python. Esto permitió:

Leer datos desde archivos CSV y bases de datos SQL.

Consultar y filtrar información basada en criterios específicos.

Transformar y organizar datos para su posterior análisis.

4. Conclusión

Este repositorio documenta el aprendizaje y desarrollo de habilidades en POO, desde conceptos teóricos hasta la creación de un sistema funcional completo. El proyecto final combina programación orientada a objetos, integración de bases de datos SQL y desarrollo de interfaces gráficas, demostrando la aplicación práctica de los conceptos aprendidos.

Espero que este repositorio sea de utilidad para comprender el proceso de aprendizaje y desarrollo de sistemas complejos.
